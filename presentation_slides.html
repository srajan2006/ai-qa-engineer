Slide 2: Problem Statement

Slide 02
  • Manual QA Bottlenecks: Writing comprehensive unit tests covering edge cases is time-intensive and developer-dependent.
  • Shallow Happy-Path Testing: Developers frequently test only valid inputs, missing zero-division, type mismatches, and boundary crashes.
  • Security Blindspots: Vulnerabilities such as SQL injections and hardcoded secrets routinely slip into production repositories.
  • Fragmented Tooling: Linters, security scanners, and test runners operate in disconnected silos without unified synthesis.

"In software engineering today, testing is fragmented. Developers juggle multiple tools without unified synthesis, and manually triaging failed tests consumes hours of engineering time. Our system solves this by introducing automated multi-agent reasoning."

Slide 4: System Architecture & Data Flow

Slide 04
  • Presentation Layer: Modern Dark Glassmorphic Dashboard with real-time state polling and code inspector.
  • Backend API Layer: FastAPI asynchronous REST backend managing non-blocking analysis jobs.
  • Orchestration Layer: LangGraph StateGraph managing sequential agent activations across a shared QAState.
  • Verification Engines: Subprocess execution of Pytest, pytest-cov, Ruff, and Bandit.
🎙️ Speaker Notes (What to say)

"Our architecture follows a clean 4-tier model. When the user loads a project, FastAPI triggers our LangGraph state machine. Each agent mutates a shared state dictionary in memory, driving both deterministic tools and Gemini API calls."

Slide 5: Multi-Agent Catalog (10 Specialized Agents)

Slide 05
  • 1. Supervisor Agent: Graph initializer and finalizer; logs timestamps and tracks lifecycle.
  • 2. Code Loader Agent: Discovers Python files, parses metadata, and extracts source buffers.
  • 3. Code Analyzer Agent: Computes AST cyclomatic complexity and checks PEP 8 compliance via Ruff.
  • 4. Security Agent: Executes Bandit to detect SQL injections, command injections, and hardcoded secrets.
  • 5. Test Generator Agent: Prompts Gemini 2.5 Flash to synthesize unit tests for edge cases and failure modes.
  • 6. Test Runner Agent: Executes tests in an isolated subprocess and captures pass/fail counts.
  • 7. Coverage Agent: Measures line-by-line coverage percentage across modules via pytest-cov.
  • 8. Bug Analysis Agent: Correlates test failures and security flags into categorized defect reports.
  • 9. Root Cause Agent (RCA): Explains WHY defects occurred, business impacts, and code-level fixes.
  • 10. QA Report Agent: Calculates Overall Quality (0–100), Security Score, and writes executive summaries.
🎙️ Speaker Notes (What to say)

"Instead of using a single prompt that tries to do everything, we divide responsibilities among 10 specialized agents. This guarantees accuracy, avoids context degradation, and allows isolated error recovery."

Slide 8: Root Cause Analysis (RCA) Deep Dive

Slide 08
  • Why It Happened: Explains the fundamental reason (e.g., missing denominator guard before division).
  • Affected Component: Pinpoints exact module and function (e.g., calculator.py → divide()).
  • Business & Technical Impact: Assesses application crash risks and exception propagation.
  • Prescribed Remediation: Supplies verified drop-in code fix with confidence rating (e.g., 96%).
🎙️ Speaker Notes (What to say)

"The standout feature of our platform is Root Cause Analysis. Rather than simply alerting that a test failed, our RCA agent explains why it failed, what business risk it poses, and generates a concrete Python code snippet to fix it."

Slide 9: Scoring Metrics & Human-in-the-Loop Governance

Slide 09
  • Overall Quality Score (0–100): Weighted: Code Quality (30%) + Test Pass Rate (25%) + Coverage (20%) - Bug Penalties (25%).
  • Security Score (0–100): Point deductions based on CVSS severity: Critical (-20), High (-10), Medium (-5).
  • Human-in-the-Loop Sign-off: Interactive governance interface allowing QA leads to officially Approve or Reject reports with audit trail notes.
🎙️ Speaker Notes (What to say)

"We compute an Overall Quality Score and Security Score using a transparent, multi-metric formula. The platform includes a Human-in-the-Loop sign-off interface, allowing QA leads to approve releases or request re-analysis."
